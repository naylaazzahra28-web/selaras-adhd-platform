# Selaras - Edukasi ADHD untuk Orang Dewasa

Platform edukasi digital yang membantu orang dewasa memahami dan mengelola ADHD (Attention-Deficit/Hyperactivity Disorder) melalui materi pembelajaran yang mudah dipahami.

## Tentang Proyek
Proyek ini merupakan hasil rebuild dan redesign dari repository latihan pemrograman web [jedx-learning-platform](https://github.com/fanhdt/jedx-learning-platform), dikembangkan menjadi platform edukasi kesehatan mental dengan tema ADHD pada orang dewasa.

## Fitur
- Landing page responsif (desktop, tablet, mobile)
- Navigasi dengan hamburger menu di perangkat mobile
- Daftar materi pembelajaran ADHD
- Formulir kontak
- Integrasi Google Maps

## Teknologi
- HTML5
- CSS3
- JavaScript (Vanilla)
- Feather Icons
